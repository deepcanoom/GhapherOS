# @ghapheros/core

Visor 3D de GhapherOS. Lee el proyecto desde `data/example.json` (o desde el navegador si hay una copia guardada) y lo renderiza como centro de comando.

- `viewer.js`: escena, escenarios, métricas, tarjetas y editor del proyecto.
- `window.GhapherOS`: bus de eventos (`on`, `emit`) usado por las extensiones.
- Formato del proyecto: [`schemas/project.schema.json`](../../schemas/project.schema.json).
